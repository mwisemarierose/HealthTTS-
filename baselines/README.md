# Baselines

Checkpoint files are **not** stored in git.

On Orchard they live under:

```text
/project/community/rmwisene/tts_baselines/
├── mms_tts_kin/       # https://huggingface.co/facebook/mms-tts-kin
└── kinya_flex_tts/    # https://huggingface.co/wixdivin/kinya-flex-tts
```

Download: `bash scripts/download_baselines.sh`  
Config: `configs/baselines.yaml`
